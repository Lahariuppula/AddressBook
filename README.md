# Address Book Management System

## Description
A menu-driven Address Book Management System developed in C to manage contact information. The application allows users to create, search, edit, delete, and list contacts, with file handling for storing and retrieving contact details.

## Features
Create new contacts with name, phone number, and email.
Validate phone numbers and email addresses.
Search contacts by name, phone number, or email.
Edit existing contact details.
Delete contacts with confirmation.
Display all saved contacts.
Save and load contacts using file handling.

## Technologies Used
Programming Language: C

## Concepts
Structures, Pointers, Functions, String Handling, File Handling

## Menu Options
- Create Contact
- Search Contact
- Edit Contact
- Delete Contact
- List All Contacts
- Save Contacts
- Exit
